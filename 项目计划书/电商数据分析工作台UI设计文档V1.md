# 电商数据分析工作台 UI 设计文档（V1.0）

> 文档定位：本文档是《电商数据分析工作台·产品设计方案 V1.0》第 4 章「前端界面设计」的完整展开版，定义第一版 UI 的全部设计规范，包括设计原则、信息架构、页面详设、组件规范、交互状态、视觉规范与验收标准。
>
> 产品定位：让不懂 SQL 的非业务人员（运营、管理者、决策者）也能自己查数据、看懂数据、拿数据做决策。
>
> 核心形态：资源包模式（选包即懂业务）+ 引导式前端（点方向就出分析）+ 三段式回答（结论、数据支撑、行动建议）。

## 1. 设计目标与原则

### 1.1 设计目标

V1.0 的 UI 设计围绕四个可量化的目标展开：

| 编号 | 目标 | 量化标准 |
| --- | --- | --- |
| G1 | 零门槛上手 | 新用户从打开页面到完成第一次分析不超过 1 分钟 |
| G2 | 无术语障碍 | 全流程不出现 SQL、表、字段、维度等术语 |
| G3 | 结论可读可信 | 回答 3 秒内能看懂结论，10 秒内能溯源到数据 |
| G4 | 分析可沉淀 | 任意一次分析可一键保存到看板并回看 |

### 1.2 设计原则

| 原则 | 具体做法 | 对应目标 |
| --- | --- | --- |
| 零门槛 | 示例问题按钮、方向引导、点击即问，不出现空白输入框 | G1 |
| 引导式 | 看大盘、看趋势、看结构、找异常四方向引导，每步给出下一步 | G1、G2 |
| 可读性 | 结论卡片、关键数字高亮、图表化呈现、三段式回答 | G3 |
| 可溯源 | 每个结论可展开查看数据来源与对应 SQL | G3 |
| 可沉淀 | 保存看板、历史会话、分享 | G4 |
| 一致性 | 同一指标同一口径同一配色，全站统一 | G1、G3 |

### 1.3 设计原则的执行准则

- **用户永远不面对空白输入框**：任何页面都有可点击的引导入口，输入框是可选能力而非默认形态。
- **每一屏只回答一个问题**：不把总览、分析、详情堆在同一屏，按动线分屏承载。
- **数字先说结论再给依据**：任何数据呈现必须先有结论句，再展开数据与图表。
- **失败不裸奔**：加载、空态、错误态都有引导文案与下一步动作。

## 2. 设计基调

### 2.1 整体风格

- **风格关键词**：轻量、专业、可信。不做炫技动画，不做重阴影与高饱和渐变，让业务用户感到「这是公司内部工具，数据可靠」。
- **视觉语气**：像一位懂行的同事在汇报，克制、直接、有结论。
- **布局语言**：卡片化 + 分区化，一屏一个主任务，信息密度适中。

### 2.2 色彩语义

- **涨跌色**：全站统一「涨绿跌红」（互联网 BI 惯例），与股票软件习惯不同处用文字符号辅助（▲ 涨 / ▼ 跌），避免只靠颜色传达。
- **状态色**：成功绿、警告琥珀、危险红、信息蓝，只用于明确业务判断，不做装饰。
- **强调色**：全站只保留一个主强调色（见第 7 章色板），用于主按钮与关键数字高亮。

## 3. 信息架构与页面流转

### 3.1 四屏信息架构

| 屏 | 页面 | 核心元素 | 用户动作 | 出口 |
| --- | --- | --- | --- | --- |
| 第 1 屏 | 资源包选择 | 品牌区、资源包卡片、数据域说明 | 选择电商包 | 进入工作台 |
| 第 2 屏 | 工作台总览 | 顶部工具条、四张指标总览卡 | 看整体、选时间 | 点方向进入分析 |
| 第 3 屏 | 引导式分析 | 四方向按钮、图表区、智能追问 | 点方向、看图、追问 | 深化或保存 |
| 第 4 屏 | 结果沉淀 | 分析路径条、保存看板、我的看板 | 保存、回看、分享 | 返回分析或离开 |

### 3.2 页面流转

```
资源包选择页 ──选择电商包──▶ 工作台总览 ──点方向──▶ 引导式分析
      ▲                          │                     │
      │                          ▼                     ▼
  返回选包 ────────────────◀── 我的看板 ◀──保存── 分析路径条（总览→下钻→归因）
```

- 任意分析页可随时返回总览，不丢失上下文。
- 「我的看板」作为常驻入口，可一键回到历史分析。

## 4. 页面设计详述

### 4.1 资源包选择页

#### 4.1.1 布局

```
┌─────────────────────────────────────────────┐
│ 品牌区：Logo + 「问数据，不用写 SQL」副标题      │
├─────────────────────────────────────────────┤
│ 资源包卡片区（横排，flex 换行）                 │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐        │
│  │ 🛒 电商  │ │ 🏪 零售  │ │ 📱 金融  │ ...   │
│  │ 已选择 ✓ │ │ 即将开放 │ │ 即将开放 │        │
│  └─────────┘ └─────────┘ └─────────┘        │
├─────────────────────────────────────────────┤
│ 页脚：一句话说明（数据不出域、仅限内部使用）      │
└─────────────────────────────────────────────┘
```

#### 4.1.2 卡片元素

| 元素 | 说明 | 示例 |
| --- | --- | --- |
| 名称与图标 | 领域识别，一眼可辨 | 🛒 电商 |
| 数据域说明 | 一句话说明覆盖场景 | 订单、商品、用户、营销全链路 |
| 预置能力 | 预置指标数、分析模板、示例问题数 | 8 大指标 · 4 套分析模板 · 12 个示例问题 |
| 适用角色 | 说明适合谁用 | 运营 / 店长 / 业务负责人 |
| 状态标识 | 已选择 / 可选 / 即将开放 | 首版电商可选，其余置灰 |

#### 4.1.3 状态与交互

| 状态 | 表现 | 交互 |
| --- | --- | --- |
| 默认 | 白底、细边框、悬停轻微上浮 | 点击进入工作台 |
| 已选择 | 主色描边 + 右上角「已选择」角标 | 再次点击提示已在当前包 |
| 即将开放 | 置灰 + 「即将开放」标签 | 点击弹提示：敬请期待 |

### 4.2 电商数据工作台

工作台是核心页面，六个区块从上到下构成一条完整分析动线：**看整体 → 选方向 → 看图 → 追问 → 走路径 → 沉淀**。

#### 4.2.1 顶部工具条

| 元素 | 内容 | 说明 |
| --- | --- | --- |
| 页面标题 | 电商数据工作台 | 常驻左上 |
| 时间选择器 | 今天 / 本周 / 本月 / 自定义 | 切换后全局指标与图表联动刷新 |
| 数据范围 | 当前部门（只读展示） | 与行级权限一致，不可越权 |
| 操作 | 保存到看板（主按钮） | 将当前分析一键保存 |

#### 4.2.2 指标总览卡

四张指标卡并排，是用户进入工作台看到的第一屏信息。

| 指标 | 示例值 | 环比 | 用途 |
| --- | --- | --- | --- |
| GMV | 128.6 万 | ▲ 12.3% | 整体营收体量 |
| 订单量 | 8,420 | ▲ 6.1% | 交易规模 |
| 转化率 | 3.42% | ▼ 0.8% | 效率变化 |
| 退款率 | 2.15% | ▼ 0.3% | 质量信号 |

> 注：以上数值均为示例数据，仅说明界面形态。

每张卡结构：

```
┌───────────────┐
│ GMV           │  ← 指标名（12px 灰）
│ 128.6 万      │  ← 数值（20px 加粗，主色）
│ ▲ 12.3% 环比  │  ← 涨跌（绿/红 + 符号）
└───────────────┘
```

- 数值异常（如环比跌幅超过阈值）时，卡片右上角出现「异常」角标，点击直接跳转「找异常」分析。
- 点击卡片可进入该指标的细化分析（下钻）。

#### 4.2.3 引导式分析区（核心区）

**文案**：「你想看什么？」—— 四个方向按钮，每个按钮下方一行小字说明触发内容。

| 方向 | 主文案 | 副文案 | 触发的分析 |
| --- | --- | --- | --- |
| 看大盘 | 📊 看大盘 | 整体表现如何 | 核心指标总览与达标情况 |
| 看趋势 | 📈 看趋势 | 时间走势变化 | 时间序列图表与拐点提示 |
| 看结构 | 🍩 看结构 | 品类/渠道占比 | 构成分析与排行 |
| 找异常 | 🚨 找异常 | 指标异动提醒 | 异常指标清单与归因引导 |

- 按钮采用大点击区（≥ 72px 高），适合业务用户快速点选。
- 已选方向高亮，再次点击收起分析。

#### 4.2.4 图表区与智能追问

- **图表区**：选中方向后展示对应图表（趋势线、占比图、排行柱状图），图表右上角带口径说明（时间范围、指标定义）。
- **智能追问**：图表下方给出 2～3 个追问建议按钮，引导用户从浅层问题走向归因问题。

| 场景 | 追问示例 |
| --- | --- |
| 看趋势后 | 哪个品类拉动了增长？／周末与工作日差异大吗？ |
| 看结构后 | 这个品类主要由哪些渠道贡献？／环比变化最大的是哪个？ |
| 找异常后 | 异常最可能的直接原因是什么？／去年同期表现如何？ |

- 追问按钮点击后直接执行新分析，图表联动替换，分析路径条推进。

#### 4.2.5 分析路径条

**位置**：图表区下方，常驻展示当前分析所处的环节。

```
① 总览  →  ② 下钻（点品类）  →  ③ 归因（为什么）
```

- 当前环节高亮，已完成环节可点击回退。
- 让用户始终知道「我在分析流程的哪一步」，不迷路。

#### 4.2.6 我的看板

- 常驻入口（顶部工具条右侧「我的看板」）。
- 看板页：分析卡片列表（标题、指标、时间范围、缩略图、创建时间）。
- 操作：回看、重新分析、重命名、删除、分享（生成分享链接或图片）。

### 4.3 多维交互设计

#### 4.3.1 维度选择器

- 支持四个维度自由组合：**时间 × 品类 × 渠道 × 地区**。
- 交互形态：下拉选择器 + 已选条件胶囊展示。
- 示例：选择「华东地区」「最近 30 天」「全部品类」后，全部图表同步刷新。

#### 4.3.2 图表联动与下钻

- **点击联动**：点击柱状图中的某个品类，下方立即展开该品类明细与趋势图。
- **下钻**：分析路径条同步从「总览」推进到「下钻」环节。
- **返回**：点击路径条「① 总览」回退，图表恢复上级视图。

#### 4.3.3 示例问题与智能追问

- 工作台右下角常驻「示例问题」浮动按钮，展开 12 个预置问题胶囊，点击即问。
- 回答区下方常驻「智能追问」建议，引导深挖。

## 5. 组件规范

### 5.1 指标卡

| 项目 | 规范 |
| --- | --- |
| 用途 | 展示单个核心指标 |
| 结构 | 指标名、数值、环比、可选异常角标 |
| 尺寸 | 四卡并排，卡片最小宽 200px，高 96px |
| 数值字体 | 20px 加粗，主色 |
| 状态 | 默认 / 悬停（轻上浮）/ 点击下钻 |

### 5.2 方向按钮（引导按钮）

| 项目 | 规范 |
| --- | --- |
| 用途 | 引导式分析区四个方向入口 |
| 结构 | 图标 + 主文案 + 副文案 |
| 尺寸 | 最小宽 240px，高 72px，大点击区 |
| 状态 | 默认 / 悬停 / 已选（主色描边高亮） |
| 文案规范 | 主文案 ≤ 4 字，副文案 ≤ 10 字 |

### 5.3 结论卡片（三段式回答）

| 区块 | 内容 | 样式 |
| --- | --- | --- |
| 结论 | 一句话业务结论，≤ 30 字 | 加粗，最大字号 |
| 数据支撑 | 关键数字 + 迷你图表 | 数字高亮主色 |
| 行动建议 | 1～2 条可执行建议 | 建议块，浅底衬托 |
| 溯源 | 「查看 SQL / 查看数据」折叠 | 默认收起，点击展开 |

结论卡片是回答的默认形态，聊天气泡式回答仅作为辅助形态。

### 5.4 图表容器

| 项目 | 规范 |
| --- | --- |
| 用途 | 承载趋势、占比、排行、对比图表 |
| 结构 | 标题、口径说明、图表、图例 |
| 口径说明 | 常驻图表右上角，含时间范围与指标定义 |
| 配色 | 使用第 7 章数据可视化配色，不超过 5 色 |
| 空态 | 无数据时显示「暂无数据」+ 引导文案 |

### 5.5 追问按钮 / 示例问题胶囊

| 项目 | 规范 |
| --- | --- |
| 用途 | 降低表达成本，点击即问 |
| 形态 | 胶囊按钮，文案 ≤ 15 字 |
| 数量 | 每个场景 2～3 个，避免选择负担 |
| 文案规范 | 以业务问题写，不用术语（如「哪个品类拖累了整体」而非「各品类 GMV 贡献度」） |

### 5.6 分析路径条

| 项目 | 规范 |
| --- | --- |
| 用途 | 展示分析所处环节，支持回退 |
| 结构 | 环节节点 + 箭头，当前节点高亮 |
| 环节 | 总览 → 下钻 → 归因（V1.0 三段） |
| 行为 | 点击已完成环节回退 |

### 5.7 看板卡片

| 项目 | 规范 |
| --- | --- |
| 用途 | 展示已保存的分析 |
| 结构 | 标题、关键指标、时间范围、缩略图、创建时间 |
| 操作 | 回看、重新分析、重命名、删除、分享 |

## 6. 交互与状态设计

### 6.1 加载态

- 首屏与图表区使用骨架屏（Skeleton），不出现空白闪烁。
- 查询超过 2 秒时显示轻量进度提示「正在查询数据…」。

### 6.2 空态

- 无数据时：显示「当前条件下暂无数据」，并给出两个建议动作：调整时间范围 / 查看其他方向。
- 空态不出现报错感，始终有下一步。

### 6.3 错误态

| 场景 | 提示文案 | 下一步动作 |
| --- | --- | --- |
| 查询失败 | 「数据查询出错了，请稍后再试」 | 重试按钮 |
| 问题不明确 | 「可以再具体一点吗？例如：上个月的 GMV 是多少」 | 引导补充条件 |
| 权限不足 | 「当前账号暂无该数据范围权限」 | 返回上一步 |

- 所有错误提示使用业务语言，不暴露技术细节。

### 6.4 成功反馈

- 保存看板成功：轻提示「已保存到我的看板」+ 快捷跳转。
- 分享成功：显示链接 / 图片已生成。

### 6.5 响应式适配

| 断点 | 布局策略 |
| --- | --- |
| ≥ 1024px（桌面优先） | 完整四屏布局，六区块完整呈现 |
| 768～1023px | 指标卡 2×2，方向按钮 2×2，图表单列 |
| < 768px | 单列布局，顶部工具条收起为图标，移动端仅基础可用 |

| 结论句 | 18px | 700 | 结论卡片首行 |
| 指标数值 | 20px | 700 | 指标卡数值 |
| 区块标题 | 16px | 600 | 分区标题 |
| 正文 | 14px | 400 | 说明文字 |

### 7.4 间距、圆角与阴影

| 项目 | 规范 |
| --- | --- |
| 页面边距 | 24px |
| 卡片间距 | 16px |
| 卡片内边距 | 16px |
| 圆角 | 卡片 12px，按钮 8px，胶囊全圆 |
